# UseGrokBot

A searchable library of Grok Bot use cases, prompts and workflows.

**Find a task. Copy the prompt. Put your Grok Bot to work.**

Independent resource. Not affiliated with xAI.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- Three.js companion mascot (eyes follow the cursor)
- Local structured content — no auth, no database

## Develop

```bash
npm install
npm run dev
```
